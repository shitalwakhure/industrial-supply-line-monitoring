## Industrial Supply Line – Adaptive Material Monitoring & POST

## Overview
ATmega328P-based intelligent material monitoring and supply-line safety system.

## Features
- Adaptive material monitoring
- Safety condition detection
- Power-On Self-Test (POST)
- Alert and control system

## Hardware
- ATmega328P
- Sensors
- LEDs
- Buzzer
- LCD

## Software
- AVR Assembly
- Microchip Studio
- Proteus
